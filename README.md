## Version 3 design direction
This revision softens the visual tone: smaller/lighter headings, warmer typography, gentler section backgrounds, subtler cards, reduced contrast, and more relaxed spacing.


## V4.1 softer headline refinement
The headline system was softened again without changing the established site structure:
- changed to a gentler old-style serif stack
- reduced hero and section headline size
- regular rather than bold weight
- slightly more line height
- quieter section labels
- italic, understated Structure · Fascia · Function signature


## Version 6 — current website inspired
V5's handwritten/script experiment was removed. This version returns to the visual character of the current Wix site: clean, uncomplicated sans-serif typography, regular/light headline weights, restrained headline sizes and generous spacing. The new site's improved content and structure are retained, along with the more prominent clinic logo.


## Version 7 — logo with page headings
The clinic logo has been removed from the top navigation and placed directly with the page heading on every page. The logo is substantially larger, with the homepage using the largest treatment. Navigation is intentionally quieter so the logo and heading work together as the primary page identity.
